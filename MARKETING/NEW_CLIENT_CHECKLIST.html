Phase 2 — Create Supabase Project
3 steps · ~3 minutes
0 / 3 ▼
Sign into Supabase with the new Gmail
Go to supabase.com → Sign in with Google → Select the new Gmail account.
Create a new project
Click New Project → Name it after the shop → Region: South Asia (Singapore) → Set a strong database password → Click Create Project.
Wait ~2 minutes for it to finish setting up.
Copy Project URL and Anon Key → paste into Client Details above
Settings → API → Copy Project URL (paste in "Supabase Project URL" field above) → Copy anon public key (save it — needed in config.js later).
🛠️

3 steps · ~2 minutes
0 / 3 ▼
📌 Run these in the new Supabase project you just created — not the main one.
Open Supabase SQL Editor
In the new project → SQL Editor (left sidebar) → New Query.
Paste and run schema.sql
Open schema.sql from your SAAS SETUP folder → Select All → Copy → Paste into SQL Editor → Click Run (Ctrl+Enter).
✅ Expected result: "Success. No rows returned."
⚠️ If you see any errors, do not proceed. Re-paste the full schema from scratch.

Phase 5 — Upload to Hostinger
3 steps · ~3 minutes
0 / 3 ▼
Create subdomain in Hostinger
Hostinger → Hosting → Subdomains → Create: clientname.swarooponline.com. This creates a new folder in File Manager.
Upload app files to subdomain folder
File Manager → Open the client's subdomain folder → Upload these files:
1. index.html — the app
2. config.js — client's Supabase credentials
3. manifest.json, sw.js, icon-192.png, icon-512.png — PWA files
Open the URL and confirm app loads
Visit https://clientname.swarooponline.com → App should show the login screen with the shop name. If blank, check that config.js is uploaded and URLs are correct.
✅
Phase 6 — Test & Hand Over
2 steps · ~1 minute
0 / 2 ▼
Client registers → set them as Admin
After the client registers their first account, run this in Supabase SQL Editor: 
UPDATE user_roles SET role = 'admin' WHERE email = 'CLIENT_EMAIL_HERE';
Replace CLIENT_EMAIL_HERE with the email from the "Client's Admin Email" field above.
Send Welcome Kit to client
Send CLIENT_WELCOME_KIT.html (filled with their details) via WhatsApp/email. Includes: their URL, first login steps, how to install on mobile, how to add staff.
